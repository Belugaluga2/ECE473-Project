## Method notes

- Kalshi: `GET /events?series_ticker=...&with_nested_markets=true` for each of the 37 monthly rain series; open times read from the nested markets. Lead times computed from `data/processed/kalshi_rain_markets.parquet` as period start (midnight Eastern) minus the event's first open time.
- PRF: `sobtpu_{2018..2025}.zip` from RMA's `state_county_crop` folder, filtered to state TX and commodity code 0088, liability, premium and indemnity summed by the two-month interval in the practice name. The 2025 file is dated Nov 14, 2026.
- PDFs (CFC 2011 and 2023, FCA EM-61.3, FCA 2012 annual report, J-PAL) were downloaded today and text-extracted; figures were read from the extracted text.
